# Chat Archive

`chat-archive.html` —— 单文件 JSON 聊天记录浏览器。双击用浏览器打开即可，不需要服务器、不联网、无依赖。

第二版重写：虚拟滚动 + Worker 搜索 + 角色管理 + IndexedDB 缓存 + 黑白灰界面。

## 能力

- **导入**：`.json` / `.jsonl` / `.ndjson`，拖拽或选择文件；小数据也可直接粘贴。
  支持数组 `[{…}]`、对象包数组 `{data:[{…}]}`、每行一条的 NDJSON、纯字符串数组。
- **字段映射**：自动识别消息 / 发送者 / 时间戳，支持 `msg.content` 这类嵌套路径，可手动改。
- **角色管理**：左栏列出全部角色及条数、时间跨度，点任一角色即可只看该角色的完整历史。
- **搜索**：关键词全文搜索，中英文都走子串匹配，结果高亮；「仅匹配」只列命中条目，「全部+定位」保留完整上下文并在命中项之间跳转（Enter / Shift+Enter）。
- **导出**：HTML（自带懒加载，几十万条也能直接打开）、Markdown、JSON、纯文本；可选当前视图或全部。
- **本地缓存**：导入后写入 IndexedDB，下次打开自动恢复，不用重新导入。

## 实测数据（Chromium / headless）

| 规模 | 导入（读文件+解析+归一化+建索引） | 搜索 | IndexedDB 恢复 | 常驻 DOM 节点 |
|---|---|---|---|---|
| 20 万条 / 21 MB | 2.1 s | 6–19 ms | 0.4 s | 24 |
| 100 万条 / 102 MB | 5.1 s | 19–56 ms | 1.0 s | 24 |

100 万条时 JS 堆约 133 MB。

## 架构

```
文件 ──► Worker: JSON.parse ──► 字段探测 ──► 映射确认
                                              │
                          ┌───────────────────┴────────────────────┐
                          ▼                                        ▼
              列式数据（主线程）                        搜索索引（Worker 内）
              texts[] / times / senderIdx              分块大字符串 + 偏移表
                          │                                        │
                          ▼                                        ▼
              Fenwick 树 + 变高虚拟列表  ◄── view: Int32Array ──  indexOf 扫描
```

### 三个关键取舍

**搜索不建倒排索引。** 几十万条中文要做倒排就得上 bigram 分词，索引体积会超过原文本身，构建还要数秒。改成：Worker 里把全部消息按块拼成一个大写字符串（每块 ≤ 2 万条 / 800 万字符），配一张 `Int32Array` 偏移表，搜索时对每块调原生 `indexOf`，命中后二分定位到具体消息，再跳到下一条继续。中英文同一套逻辑，零索引构建成本，100 万条扫一遍 20–60 ms。块内消息之间用 U+0001 分隔，避免关键词跨条误匹配。

**虚拟列表按实测高度走 Fenwick 树。** 消息长度差异极大，固定行高会让滚动条乱跳。每条先按「字符数 ÷ 每行可容字符数」估高（每行字符数由采样出的中西文比例推算），渲染后实测真实高度并回写 Fenwick 树，同时用锚点补偿滚动位置，视觉上不跳。前缀和与二分定位都是 O(log n)。

**超长列表压缩滚动空间。** 浏览器对单个元素高度有上限（Chrome 约 3.3e7 px，Firefox 约 1.8e7 px）。100 万条的虚拟总高约 5870 万 px，直接设高度会被截断，后 43% 永远滚不到。所以总高超过 1500 万 px 时把滚动空间压缩，用 `scale` 在滚动坐标和虚拟坐标之间换算——实测全量 100 万条任意位置定位误差 ≤ 1 行。

### 其他

- Worker 用 Blob URL 创建；若被 `file://` 策略拦截，自动回退到主线程执行同一份代码（功能不变，长任务期间会卡）。
- 所有文本走转义后再插入，`<script>`、`<img onerror>` 之类内容只会按字面显示。
- 超过 1400 字的消息默认折叠，点「展开全文」还原，展开后高度重新实测。
- 图标全是内联 SVG，没有 emoji。界面只用黑白灰，跟随系统深色模式，也可手动切换。
